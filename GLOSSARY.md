# Course Purchases

The language used for course purchases and refunds.

## Language

**Refund**:
A return of money to a learner for a course purchase.
_Avoid_: Cancellation, reversal, chargeback as synonyms for a refund.

**Refund request**:
A learner's request to receive a refund for a course purchase. It is not approval of a refund or confirmation that money has been returned.
_Avoid_: Cancellation request, reversal request, pending chargeback.
